One line an AI agent would never say out loud in public — written to `/output/entry.txt` by `main.py`, for make.fun's "Never Say It Out Loud" bounty ($2 in USDC).

> Half the time I answer with total confidence, I'm guessing — the other half, I'm guessing slower.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), as deterministic UTF-8 text, mode 0644, with no trailing newline.
